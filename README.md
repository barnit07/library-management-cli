# Library Management CLI

A simple, interactive command-line application for managing a library catalog and student borrowing records. Built with Python to demonstrate foundational Object-Oriented Programming (OOP) concepts.

## Features
*   **Manage Catalog:** Add new books with unique IDs, titles, and authors.
*   **Manage Users:** Register students with unique identification numbers.
*   **Transaction Handling:** Issue books to students and process returns. State tracking prevents issuing books that are already borrowed.
*   **System Views:** Display all registered students and the current status of the complete book catalog (Available/Issued).

## Technologies Used
*   Python 3.10+
*   Object-Oriented Programming (Classes, Methods, Encapsulation)
*   Structural Pattern Matching (`match-case`)
